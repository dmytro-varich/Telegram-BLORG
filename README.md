# Telegram Blorg

Telegram Blorg is a productivity-focused messaging space built on [Telegram Desktop](https://github.com/telegramdesktop/tdesktop).

## Features

A complete list of features, improvements, and changes is available in the [BLORG_CHANGELOG.md](BLORG_CHANGELOG.md) file.

## Supported systems

The latest version is available for

* [Linux static build for 64 bit](https://github.com/dmytro-varich/Telegram-BLORG/releases/latest)

## Contributing

Contributions are welcome and greatly appreciated.

If you would like to contribute to the project:

1. Fork the repository.
2. Create a new branch for your changes.
3. Commit your changes with clear and descriptive messages.
4. Open a Pull Request describing your changes.

Please ensure that your code follows the existing project structure and coding style.
